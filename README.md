# Paradise Nursery

Paradise Nursery is a React and Redux-based online plant shop application.

## Project Details

Paradise Nursery allows users to browse houseplants, add plants to a shopping cart, update quantities, remove items, and view the total cost of their purchases.

## Features

- Beautiful landing page
- Company information
- Three plant categories
- Six unique plants per category
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantities
- Remove products from cart
- Total price calculation
- Checkout message
- Continue Shopping button
- Responsive design
- Redux state management
